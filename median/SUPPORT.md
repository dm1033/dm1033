# Getting help

## Before you ask

- Read the [README](README.md), especially the **Usage** and **Behaviour** sections.
- Search the existing [issues](https://github.com/dm1033/dm1033/issues?q=is%3Aissue%20median) in case your question has already been answered.

## Where to go

| You want to…                                                     | Go to                                                                                                      |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Ask how to use `median()`, or check whether a result is expected | A new issue on the [Issues page](https://github.com/dm1033/dm1033/issues), with a title starting `median:` |
| Report a wrong result, crash or other bug                        | A new issue on the [Issues page](https://github.com/dm1033/dm1033/issues), with a title starting `median:` |
| Suggest a new feature or a change in behaviour                   | A new issue on the [Issues page](https://github.com/dm1033/dm1033/issues), with a title starting `median:` |
| Report a security vulnerability                                  | **Not** a public issue. Follow [SECURITY.md](SECURITY.md) to report it privately                           |
| Contribute a fix or improvement                                  | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                         |
| Report behaviour that breaks the Code of Conduct                 | The contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)                                                    |

## Asking a good question

Include:

- the exact call you made, for example `median([10, 9, 2])`
- the result you got and the result you expected
- your Node.js version (`node --version`) and the version of this package

A short code sample that shows the problem gets the quickest answer.

## What to expect

This project is maintained on a best-effort basis. There's no guaranteed response time for questions, bug reports or feature requests, and there's no paid support. Security reports are handled separately, with the target response times in [SECURITY.md](SECURITY.md).

Only the latest release, or the `main` branch before the first release, is supported. If you're on an older version, please check whether the problem still happens on the latest one.
