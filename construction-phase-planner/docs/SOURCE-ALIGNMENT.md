# Source Alignment Matrix

Tracks how the game's content aligns to the CITB GE700 (Site Safety Plus, Version 11)
volume/chapter structure supplied by the licence holder as reference material.

**Content policy:** the publications are used as *reference only* to verify facts and
identify coverage themes. No publication text is reproduced in the game — all questions,
feedback and learning notes are original wording. Detailed reading notes are kept out of
this repository.

Status key: ✅ covered by game content · 🔶 partially covered · ⬜ not yet covered ·
⏳ source pages not yet received
