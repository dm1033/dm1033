## HTML head template

Drop this into a custom-HTML block in your CMS, replacing each value per page.

```html
<!-- Primary -->
<title>PAGE TITLE</title>
<meta name="description" content="PAGE META DESCRIPTION" />
<link rel="canonical" href="https://www.temporaryworksconsulting.com/PATH" />

<!-- Open Graph -->
<meta property="og:title" content="OG TITLE" />
<meta property="og:description" content="OG DESCRIPTION" />
<meta property="og:type" content="website" />
<meta property="og:url" content="https://www.temporaryworksconsulting.com/PATH" />
<meta property="og:image" content="https://www.temporaryworksconsulting.com/og-image.jpg" />
<meta property="og:site_name" content="Temporary Works Consulting" />

<!-- Twitter / X -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="OG TITLE" />
<meta name="twitter:description" content="OG DESCRIPTION" />
<meta name="twitter:image" content="https://www.temporaryworksconsulting.com/og-image.jpg" />

<!-- Robots / language -->
<meta name="robots" content="index,follow" />
<meta http-equiv="content-language" content="en-GB" />

<!-- JSON-LD: include relevant blocks from /schema -->
<script type="application/ld+json">{ ...ProfessionalService block... }</script>
```
