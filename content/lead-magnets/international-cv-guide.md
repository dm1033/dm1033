# International Construction CV Guide

Adapting a construction CV for overseas markets. Advisory only — conventions
vary by employer; verify visa/immigration matters with qualified advisers.

## Middle East (UAE, KSA, Qatar)
- More detail accepted: 3 pages is common at senior level
- Name mega-projects and major clients explicitly
- State nationality, current location and notice/mobilisation period
- Photos are common (unlike the UK) but optional
- Emphasise: project values, international teams, harsh-environment delivery
- State visa/sponsorship status clearly and truthfully

## Singapore / Asia-Pacific
- Concise, achievement-led CVs preferred (2 pages)
- Emphasise: rail/infrastructure/data centre experience, BCA awareness if known
- Employment pass sponsorship: state your situation honestly
- Professional registrations (CEng, PE) carry significant weight

## Applying TO the UK from overseas
- 2-page, achievement-led format; no photo, no date of birth, no marital status
- State right-to-work / sponsorship requirement clearly up front
- Translate qualifications (include UK equivalency where assessed, e.g. NARIC/ECCTIS)
- Map your titles to UK norms truthfully (e.g. "Site Agent (equivalent to Site Manager)")
- Name standards you've worked to; add UK tickets if held (CSCS, SMSTS)

## Universal rules
- Mobilisation/relocation statement: available from when, family situation if relevant
- Never disguise visa status — it wastes everyone's time and ends applications
- Currency-convert project values approximately and honestly ("approx. £40m equiv.")
- Keep a master CV; produce one targeted version per market
